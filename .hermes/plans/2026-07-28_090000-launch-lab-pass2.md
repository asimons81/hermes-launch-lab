## 9. Verification Plan

After each phase:
- `npm run build` must pass with zero errors
- Every page must render with SiteHeader + SiteFooter visible
- No "Arch Linux" anywhere in the output (grep -r "Arch" app/ components/)
- No dead links (every `<Link href>` resolves to a real page)
- Footer links match nav links
- Mobile breakpoint check (devtools 375px width)

Final deploy check:
```bash
# Verify no Arch-specific copy in deployed HTML
curl -s https://hermes.tonysimons.dev | grep -i "arch linux"
# Should return nothing

# Verify all routes return 200
for path in / /features /pricing /docs /docs/quickstart /docs/skills /docs/vault /docs/cron /faq /status; do
  code=$(curl -s -o /dev/null -w "%{http_code}" https://hermes.tonysimons.dev$path)
  echo "$path → $code"
done
```
